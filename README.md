# URL Uploader NEXT

Standalone Telegram URL uploader based on the workflow of LISA-KOREA/UPLOADER-BOT-V4.

Target: 3900 MB maximum file size using an MTProto assistant session. This project is completely separate from CineUniverse-Telegram-MiniApp.
